# Pick & Roll Lab · 挡拆实验台

> 一个帮普通球迷**看懂球**的攻防阅读解释器。
> 不教你怎么打球，而是教你读懂：**防守做了一个选择，于是哪里出现了机会。**

以「高位挡拆」为第一个教学案例，用可交互的战术板演示——
当你以防守视角选择不同的应对方式，进攻会暴露出哪些机会点、球该怎么流转、最后如何飞向篮筐。

---

## 这是什么 / 不是什么

**是**：一个攻防因果的「解释器」。核心价值是讲清楚这条链路：

```
挡拆发起 → 防守做出选择 → 暴露代价 → 球该看哪里 → 飞向篮筐终结
```

**不是**：比赛游戏、战术百科、数据统计工具。
没有比分、命中率、胜负判定，也不是「正确/错误」测验——选防守是**代入防守视角看代价**，没有对错。

---

## 核心玩法

1. 进场：挡拆已发起，提示你「如果你是防守，你会怎么应对？」
2. **选一种防守反应**（共 7 种，见下）。
3. **分步剧情**：点「下一步」，逐步演出防守的动作——每步只聚焦当前在动的球员，配解说字幕。
4. **揭示机会点**：剧情走完，按「看球顺序」逐个高亮暴露的机会点（按质量分高/中/低三色）。
5. **点机会点看完整回合**：球员跑位 + 防守移动 + 球的传导，最后**球飞向篮筐**完成终结。
6. 右侧给出「一句话看懂」总结，提炼这种防守的本质取舍。

### 7 种防守反应

| 防守 | 英文 | 一句话 |
|------|------|--------|
| Over 挤过 | Over / Fight Over | 死贴着追上方，专防投篮（含「追屁股」极端版） |
| Under 绕下 | Go Under | 从掩护下方钻过，放掉外线投篮 |
| Drop 沉退 | Drop | 大个后撤护框，放掉中距离 |
| 强延误 | Hard Hedge / Show | 大个冲出弧顶强干扰，逼你后撤 |
| 弱延误 | Soft Hedge / Flat | 小幅虚晃保阵型，逼你投中距离 |
| Switch 换防 | Switch | 干脆换人，但会换出错位 |
| Trap 夹击 | Trap | 两人包夹逼出球，但放空了一个人 |

### 球员配置（可选）

- **持球人**：投射型 / 突破型 / 传球型
- **掩护人**：顺下型 / 空间型 / 策应型

配置会用 ★ 标出与当前球员类型最契合的机会点。

## 项目结构

```
.
├── index.html            # 页面骨架 + 球场 SVG 线条
├── src/
│   ├── css/style.css     # 深色风格、球场、圆点、机会点、轨迹线
│   ├── data/data.js      # 全部战术数据（站位/7种防守/机会点/回合脚本）
│   └── js/app.js         # 交互逻辑与演示引擎
├── README.md
├── LICENSE
└── .gitignore
```

**数据与逻辑分离**：所有战术内容（站位坐标、防守剧情、机会点轨迹）都写在 `data.js`，
`app.js` 只负责渲染与播放。想新增/调整一个机会点或防守，只改数据即可。

### 关键约定

- **编号**：进攻 `A1`–`A5`、防守 `D1`–`D5`，按场上位置（A1 控卫持球、A5 中锋掩护…）。
- **坐标系**：`x` 0–100（左→右），`y` 0–100（0 = 篮筐侧顶部，100 = 半场底）。与球场 SVG 一致，不翻转。
- **回合脚本**：每个机会点带一段 `play`，描述分步的球员跑位与传导，终结统一为「球飞向篮筐」。

## 本地运行

纯静态项目，无需构建、无依赖。任选其一：

```bash
# Python
python3 -m http.server 8000

# 或 Node
npx serve .
```

然后打开 `http://localhost:8000`。

> 直接双击 `index.html` 也可运行，但建议用本地服务器以避免个别浏览器的本地文件限制。

## 部署（EdgeOne Pages）

本项目是纯静态站点，可直接部署到 [EdgeOne Pages](https://edgeone.ai/products/pages)：

1. 将仓库推送到 GitHub。
2. 在 EdgeOne Pages 控制台关联该仓库。
3. 构建配置：
   - 构建命令：**留空**（无需构建）
   - 输出目录：**`/`**（项目根目录）
4. 部署完成即可访问。

其它静态托管（GitHub Pages / Vercel / Netlify）同理，输出目录均为根目录。
